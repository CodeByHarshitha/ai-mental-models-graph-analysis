# Understanding and Comparing Human Perceptions of Artificial Intelligence Using Graph Networks

## Overview
This project models individual human perceptions of Artificial Intelligence as weighted concept networks using **NetworkX**, **Sentence Transformers**, **Scikit-learn**, and **Plotly**. By converting open-ended survey responses into cognitive maps, the pipeline quantifies which concepts sit at the core of public understanding, measures structural and semantic similarity across respondents, and clusters participants into distinct mental-model archetypes.
